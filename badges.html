How to add badges in Nuvio

1. Tap Copy URL on any set above
2. Open Nuvio → Settings → Streams
3. Scroll to Fusion badges URL
4. Tap the URL field, paste, then tap Import
5. You'll see "1/3 URLs imported" — it worked!
💡 Nuvio supports up to 3 badge sets at once — combine sets for the best coverage
