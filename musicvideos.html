YouTube API Key
Free · 10,000 requests/day from Google
✅
Get your free API key in 5 minutes:
  1. Go to Google Cloud Console and create a new project
  2. Go to APIs & Services → Library
  3. Search for YouTube Data API v3 and enable it
  4. Go to APIs & Services → Credentials
  5. Click Create Credentials → API Key and copy it
🔑 Open Google Cloud Console
2
YouTube Cookies
Required for video playback
✅
Why do I need cookies? YouTube requires you to be logged in to stream videos. Your cookies prove you're a real account — they're stored securely on your personal manifest and only used for playback.

How to export cookies from your browser:
  1. Install Get cookies.txt LOCALLY in Chrome or Brave
  2. Go to youtube.com and make sure you're logged in to your Google account
  3. Click the extension icon in your toolbar
  4. Click Export for youtube.com
  5. Upload the file below
